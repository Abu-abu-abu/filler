# Filler — Rust-бот

Проект содержит игрока для игры Filler, визуализатор и скрипт для матчей в официальном игровом движке.

## Локальная сборка

Из PowerShell:

```powershell
cd .\solution
cargo fmt --check
cargo test
cargo build --release
```

Тесты проверяют разбор поля и фигуры, правила пересечения, границы поля, выбор допустимого хода и формат ответа.

## Проверка отдельного бота

Корневой `Dockerfile` собирает только Rust-бота. Он не запускает игровой движок:

```powershell
cd 'C:\Users\Мансур\Desktop\filler'
docker build -t filler-player .
Get-Content .\solution\sample-input.txt -Raw | docker run --rm -i filler-player
```

Числа в ответе — координаты для движка. На тестовом поле они могут отличаться; фиксированного ответа `1 2` у задания нет.

## Матчи против игровых роботов

Распакуйте предоставленный `filler.zip` в корень проекта так, чтобы появилась папка `docker_image/`. Затем из корня проекта запустите:

```powershell
.\run-match.ps1
```

Скрипт собирает официальный образ движка, запускает unit-тесты и собирает бота внутри контейнера, затем проводит матчи на `map01` с фиксированным seed против `bender`, `h2_d2`, `wall_e` и `terminator`, меняя позиции игроков. Docker Desktop должен работать с контекстом `desktop-linux`.

Исполняемые файлы, карты и роботы из архива локальные и исключены из Git; для повторного запуска после клонирования проекта распакуйте архив заново.

## Визуализатор

Откройте `visualizer/index.html`, вставьте полный вывод одного хода движка и нажмите **Показать поле**.

## Стратегия

Бот перебирает допустимые позиции фигуры, соблюдает обязательное пересечение ровно одной своей клеткой и оценивает ходы по продвижению к сопернику, блокированию соседних клеток и сохранению пространства.
